# Scribble

Scribble is a landing page for an AI-powered writing assistant designed to help people draft faster, improve their writing, and get past the blank page.

This project was built from scratch with a focus on clean UI, responsive design, and a simple SaaS-style user experience.


## Features

- Responsive navbar with mobile-friendly layout
- Hero section with clear calls to action
- AI writing preview section
- Trusted companies/logo strip
- Features section
- How It Works section
- Pricing section with Free, Pro, and Team plans
- Monthly/Annual pricing toggle
- Testimonials section
- FAQ section
- Final CTA section
- Responsive footer
- Fully responsive across desktop, tablet, and mobile


## Built With

- HTML
- CSS
- JavaScript
- Lucide Icons


## What I Learned

Building Scribble helped me get more comfortable with responsive layouts, CSS Flexbox and Grid, spacing, typography, component-like section structure, and making a page adapt properly across different screen sizes.

A big part of the project was also learning how to stop designing only for desktop and actually think about how each section behaves on tablets and phones.
